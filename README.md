# NEXUS — панель управления Discord-сервером

Демонстрационный сайт бота **NEXUS**: лендинг, выбор сервера и полноценная панель управления.

## Возможности панели

- Обзор сервера и живые метрики
- Аналитика: рост, сообщения, войсы, топ каналов
- Участники: поиск, фильтры, варны / мут / бан
- Журнал модерации и создание кейсов
- Каналы, роли и права
- Автомод, команды и автоответы
- Приветствия и конструктор эмбедов
- Логи аудита, тикеты, розыгрыши, уровни XP
- Настройки модулей бота

Интерфейс на русском, данные — демо-сервер **ASTRAL**.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`.

```bash
npm run build
npm run preview
```
